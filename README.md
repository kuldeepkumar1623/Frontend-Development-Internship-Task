# She Can Foundation Website

A modern and attractive NGO landing page created for the She Can Foundation Frontend Internship Task.

## Features
- Responsive Design
- Modern UI/UX
- Smooth Hover Animations
- Hero Section
- About Section
- CTA Section
- Footer
- Beginner Friendly Code

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was created to support the mission of empowering women through education, mentorship, and opportunities.
